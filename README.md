# PX Solutions
1. `npm install` then `cp .env.example .env` and fill values
2. `npm run dev` (form needs `vercel dev` to run /api/contact locally)
3. Deploy to Vercel; set RECAPTCHA_SECRET, RESEND_API_KEY, MAIL_FROM and VITE_RECAPTCHA_SITE_KEY. Verify pxsolutions.co.jp in Resend.
Images: drop hero.jpg and about.jpg into public/images/ (hero is blended over the animated network).
